# Contributing to Awesome Invoicing

Thanks for helping keep this list useful and accurate. This is a curated list, not an exhaustive directory — quality and relevance matter more than quantity.

## What belongs here

A tool is a good fit if it is:

- **A real, usable invoicing tool** — one a freelancer or small business could adopt today. Not a blog post, template pack, or abandoned project.
- **Relevant to the list's focus** — free, standards-compliant (EN 16931 / XRechnung / ZUGFeRD / Peppol BIS / Factur-X), and/or AI-native (MCP, assistant skill, CLI, or conversational). Enterprise-only platforms go in the *Enterprise compliance networks* section.
- **Actively maintained** — the product should be live and supported.

## How to add or edit an entry

1. Fork the repo and create a branch.
2. Add your entry to the most appropriate section, keeping entries in a sensible order within the section.
3. Use this format:

   ```
   - **[Tool Name](https://example.com)** — One neutral, factual sentence describing what it does. `Tag` `Tag`
   ```

4. Keep descriptions **neutral and factual**. No marketing language, superlatives, or "best" claims. Describe what the tool *does*, not why it's great.
5. Use the existing tags where they apply: `Free forever`, `Free`, `Freemium`, `Free tier`, `Paid`, `Enterprise`, `EN 16931`, `Peppol`, `No signup`, `MCP`, `Skill`, `CLI`, `GPT Store`, `Poe`, `In-app AI`, `API`, `Mobile`, `Payments`, `Templates`, `Banking`, and country flags (e.g. `🇩🇪`).
6. If the tool fits the comparison matrix, add a row and fill every column honestly (`✅` / `⚠️` / `❌`).
7. Open a pull request describing the tool and why it fits.

## Corrections

Spotted an error — a tool that shut down, a pricing change, a compliance claim that's no longer accurate? Please open an issue or a pull request. Corrections to any entry, including Scribo's, are welcome and held to the same standard.

## Removing entries

Tools that shut down, stop being maintained, or no longer meet the criteria should be removed. Note the reason in your pull request.
